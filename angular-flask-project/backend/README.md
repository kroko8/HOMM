# Projet Angular-Flask

Ce projet est une application web qui utilise Angular pour le frontend et Flask pour le backend. 

## Structure du projet

- **frontend/** : Contient le code source de l'application Angular.
- **backend/** : Contient le code source de l'application Flask.

## Installation

### Backend

1. Naviguez vers le répertoire backend :
   ```
   cd backend
   ```

2. Installez les dépendances :
   ```
   pip install -r requirements.txt
   ```

3. Configurez l'application en modifiant le fichier `config.py` selon vos besoins.

4. Lancez l'application :
   ```
   flask run
   ```

### Frontend

1. Naviguez vers le répertoire frontend :
   ```
   cd frontend
   ```

2. Installez les dépendances :
   ```
   npm install
   ```

3. Lancez l'application :
   ```
   ng serve
   ```

## Utilisation

Accédez à l'application via votre navigateur à l'adresse `http://localhost:4200` pour le frontend et `http://localhost:5000` pour le backend.
